# 室蘭沖ボート釣り

室蘭沖のプレジャーボート釣りをモチーフにしたブラウザの釣りゲームです。

▶ 遊ぶ：https://choppermoon1623-tech.github.io/muroran-tsuri-game/

- 出船前に室蘭沖の地図をタップして釣り場を選び、日付と時刻で潮・時間帯・季節が決まります
- 魚探でタナを探し、竿先のアタリを見て合わせ、ドラグを調整しながら取り込みます
- 仕掛けは胴突き・メタルジグ・サビキの3種類。室蘭沖で出会う魚など27種
- 釣果は図鑑に記録されます（記録はこの端末のブラウザの中だけに保存）

## 注意
- ゲームです。地形は目安、魚の生態や釣れ方の数値はゲーム用の仮の値で、実際の釣りの判断には使えません
- 魚と船の絵は作者のオリジナル（AIで生成）です

## データの出典
- 水深：GEBCO Compilation Group (2025) GEBCO 2025 Grid
- 潮位：気象庁 潮位表（室蘭）2026〜2027年
