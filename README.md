# 室蘭沖ボート釣り

室蘭沖のプレジャーボート釣りをモチーフにしたブラウザの釣りゲームです。

▶ 遊ぶ：https://choppermoon1623-tech.github.io/muroran-tsuri-game/

- 出船前に室蘭沖の地図をタップして釣り場を選び、日付と時刻で潮・時間帯・季節が決まります
- 地図の「洞爺湖」ボタンで洞爺湖へ。湖ではヒメマス・ヤマベ・ニジマス・ブラウントラウト・ワカサギ・ウグイが釣れ、洞爺湖漁協の遊漁の決まり（遊漁券・針の数・期間・時間・大きさ・禁漁区。禁漁区の位置は漁協の図から写した目安）で判定します
- 魚探でタナを探し、竿先のアタリを見て合わせ、ドラグを調整しながら取り込みます。初めての人には、最初の1匹まで操作の案内が出ます。スマホでは竿先はアタリのときだけ出ます（メニューの「竿先：自動／常に表示」で切り替え）
- 背景は出船地点に近い名所（白鳥大橋と大黒島・銀屏風・地球岬・金屏風・駒ヶ岳、洞爺湖は有珠山・羊蹄山）。釣り人は季節で冬装備と夏装備に着替えます
- 仕掛けは胴突き・メタルジグ・サビキ・バケ（オオナゴ。ヒラメやサクラマスの定番）の4種類。室蘭沖と洞爺湖で出会う魚・カニ・タコなど48種
- 夏〜秋はイワシの「なぶら」が立つことがあり、船を走らせて追いかけると青物が狙えます
- 釣れたら「持ち帰る／海へ返す」を選ぶと、北海道の釣りのルール（マツカワの大きさ、サクラマスのライセンス海域、サケ・マスの河口規制、クロマグロの決まりなど）で正解か判定します
- 持ち帰った魚は料理を紹介。図鑑で魚をタップしても見られます
- レアな魚や大物を釣るとご褒美の演出。図鑑をうめると称号が上がります（メニューから記録をリセットして最初から遊べます）
- メニューに戻ると、今回の釣行（場所・仕掛け・匹数・最大・釣れたタナ）と前回を比べられます。釣れないときは、魚探の反応から次の一手（何m巻く・流し直す・仕掛けを替える）が出ます
- 釣果は図鑑に記録されます（記録はこの端末のブラウザの中だけに保存）

## 注意
- ゲームです。地形は目安、魚の生態や釣れ方の数値はゲーム用の仮の値で、実際の釣りの判断には使えません
- 釣りのルールは2026年時点で作者が調べたものです。実際に釣りをするときは、北海道や海区漁業調整委員会、洞爺湖漁協の最新の情報を必ず確かめてください
- 魚・船・料理・釣り人・背景・仕掛けの絵は作者のオリジナル（AIで生成）です

## データの出典
- 水深：GEBCO Compilation Group (2025) GEBCO 2025 Grid、北側は (2020) GEBCO 2020 Grid。洞爺湖の水深は湖の形から推定した作り物です
- 洞爺湖の決まり：洞爺湖漁業協同組合「遊漁について」（2026年）
- 河口規制：北海道「フィッシングルール2026」p.22（令和6年度の実績。河口の位置はゲームでは目安）
- 潮位：気象庁 潮位表（室蘭）2026〜2027年
