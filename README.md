# 室蘭沖ボート釣り（ゲーム）
室蘭のプレジャーボート釣りをモチーフにした釣りゲーム。魚探でタナを探し、竿先のアタリを見て合わせ、ドラグを調整しながら取り込む。index.html ＋ 魚の写真フォルダ fish/。

## いまの版：v0.1（2026-11-19）
- ポイント4つ（港外の岩礁帯／沖の根まわり／砂地のカケアガリ／沖の深場）× 季節4つ × 仕掛け3つ（胴突き・メタルジグ・サビキ）
- 魚11種：クロソイ・シマゾイ・エゾメバル（ガヤ）・アイナメ（アブラコ）・ホッケ・マガレイ・ヒラメ・ブリ（イナダ/ワラサ）・マサバ・サクラマス・マダラ
- 魚種ごとにちがうもの：すむ深さ・底質・季節・仕掛けの好み・アタリの出方（ソイはゴンゴン、カレイはコツコツ→食い込み、ヒラメは前アタリ→待つ、青物はひったくる）・引き方（根に潜る／横に走る／重い）・体長と体重の関係
- ボートは潮で流され、海底の深さが変わる。岩場で底を引きずると根掛かり
- 魚探（斜め距離で弧を描く反応）、竿先パネル、釣果カード（メジャー付き）、魚図鑑（記録はブラウザ内）
- 魚の絵はキャンバスで描いたもの（写真・素材なし）。地形・生態の数値はゲーム用の仮の値

## v0.4（2026-11-19）本物の室蘭沖
- 出船前の画面が地図になった。GEBCO_2025 の水深で色分けした室蘭沖をタップして釣り場を選ぶ（ドラッグで移動、＋－で拡大縮小、前に行った地点は白い点）
- 選んだ地点の水深と底質（推定。岩礁・砂地・泥から選び直せる）で、釣れる魚の傾向（浅い岩場／沖の根／カレイ場／深場）が決まる
- ボートは選んだ向きに流され、実際の海底地形に沿って水深が変わる（格子より細かい根は底質に合わせて足している）。浅くなったら自動で流し直し、ボタンでも流し直せる
- 日付と時刻を選ぶと、気象庁の潮位表（室蘭）の潮、月齢の潮名、日の出入りが決まる。季節は日付から自動
- 潮がよく動く時間ほど食いが立ち、流れも速くなる。朝夕のまずめは食いが上がる。夜は暗くなり、クロソイ・マイカ・アナゴがよく出る
- ゲーム内の時間は5分で1時間進む。小地図に航跡と流れの向き・速さ
- データ：`data/bathy-data.js`（GEBCO）と `data/tide-data.js`（気象庁 室蘭、2026〜2027年）は釣りナビと同じもの

- スマホ（短い辺が600px以下）は専用の配置：情報は上の帯（水深・潮・釣果・仕掛け）、くわしい情報とメニュー等のボタンは「≡」で開く。魚探は右端の細い縦帯、竿先は小さく。横向きも対応
